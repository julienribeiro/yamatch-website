# « Vu dans les stories » — dossier de passation

Nouvelle section de preuve sociale de la page d'accueil : des témoignages au
format story Instagram, qu'on fait défiler. Elle se place entre « Comment ça
marche » et les tournois publics. Maquette validée par le founder le
17/10/2026, **non implémentée**.

**Aucun contenu inventé** : la section n'est publiée qu'avec de vraies
stories (au moins 3), avec l'accord écrit des personnes. Voir `SPEC.md` §2 et §3.

| Fichier | Rôle |
|---|---|
| `PROMPT.md` | Prompt prêt à coller pour lancer l'agent IA. |
| `SPEC.md` | Instructions : contenus attendus, design, vidéos, structure HTML, tokens, décisions, délégation, critères. |
| `mockup/desktop.html`, `mockup/mobile.html` | Maquettes de référence. Les emplacements entre crochets ne doivent pas être publiés. |
| `visuals/desktop-1440.jpg`, `tablette-820.jpg`, `mobile-390.jpg` | Captures de référence. |
